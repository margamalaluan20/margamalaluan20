## Overview & Description
Welcome to the repository for **[margamalaluan20.github.io](https://margamalaluan20.github.io)**. This serves as my primary professional portfolio and development sandbox. It showcases my work as an Information Technology student and web developer, featuring responsive web applications, API integrations, and database-driven platforms.

This repository houses the source code for my frontend interface, as well as the documentation for integrated backend projects such as the *Sip & Pulse Cafe* management system, *Mystic Isles Bookstore*, and interactive API archives.

## Features List
* **Responsive UI/UX:** Mobile-first design implemented using modern CSS and Figma/Canva prototyping.
* **API Integrations:** Dynamic content rendering utilizing external JSON APIs (e.g., Genshin Impact API, Witch Hat Atelier).
* **Data Visualization:** Embedded Microsoft Power BI analytics for business intelligence dashboards.
* **Full-Stack Modules:** Showcases integration with Python/Flask backends and MySQL/PostgreSQL databases.
* **Multimedia Controls:** Custom HTML5 audio implementation and interactive DOM manipulation.
